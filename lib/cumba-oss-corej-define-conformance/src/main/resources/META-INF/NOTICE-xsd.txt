Third-party notices for the XML schemas under xsd/ in this jar
==============================================================

The jar ships the CDISC Define-XML 2.0.0 and 2.1.0 schemas, the CDISC ODM
1.3.2 and Analysis Results Metadata (ARM) 1.0 schemas they import, and the
core schemas xml.xsd, xlink.xsd and xmldsig-core-schema.xsd.

Provenance. The files were mirrored on 2026-07-03 from Lex Jansen's
define-xml-2.0-stylesheets and define-xml-2.1-stylesheets repositories
(schema/). CDISC publishes the same files, under the MIT License, in its own
GitHub organisation; verified byte-identical on 2026-10-14:
  https://github.com/cdisc-org/define-xml-2.0-stylesheets  (schema/, commit e94be4ec64c3360e86d756f54533b8f4f94f8a50)
  https://github.com/cdisc-org/define-xml-2.1-stylesheets  (schema/, commit e54eb4821ce5dfa34598b95a6bb4c58b3618662b;
      all files except define-enumerations.xsd, which CDISC updated later)
  https://github.com/cdisc-org/DataExchange-ODM            (archive/ODM1-3-2/, commit 6cb00a9cb38f245069758a7c5a6823cdf3ea48be;
      xml.xsd, xlink.xsd, xmldsig-core-schema.xsd)
The files are redistributed under the MIT License of those repositories
(section 1). The CDISC-authored schemas carry no licence statement of their
own; that the repositories' MIT grant covers them is our reading, not a
statement by CDISC. xmldsig-core-schema.xsd is additionally governed by the
W3C Software Notice and License that the file itself names (section 2).

Change made: on 2026-10-14 the W3C copyright and licence comment of
https://www.w3.org/TR/xmldsig-core/xmldsig-core-schema.xsd, missing from the
copies as CDISC publishes them, was restored verbatim in both copies of
xmldsig-core-schema.xsd. The canonical file's DOCTYPE was not restored (it
names an external DTD). No other file was changed. Full record: xsd/README.md
in the source tree of this module.
