# Vendored CDISC Define-XML schema packages

- `define-2-1/` — Define-XML 2.1.0 schema (entry point `cdisc-define-2.1/define2-1-0.xsd`)
- `define-2-0/` — Define-XML 2.0.0 schema (entry point `cdisc-define-2.0/define2-0-0.xsd`)

Both include the ODM 1.3.2 foundation schemas, the Analysis Results Metadata
(ARM) 1.0 extension, and the W3C core schemas (`xml.xsd`, `xlink.xsd`,
`xmldsig-core-schema.xsd`).

Source: mirrored 2026-07-03 from the official CDISC Define-XML stylesheet
repositories maintained by Lex Jansen (MIT-licensed):
- https://github.com/lexjansen/define-xml-2.1-stylesheets (`schema/`)
- https://github.com/lexjansen/define-xml-2.0-stylesheets (`schema/`)

The schemas themselves are developed by the CDISC XML Technologies Team.
Files are unmodified.
